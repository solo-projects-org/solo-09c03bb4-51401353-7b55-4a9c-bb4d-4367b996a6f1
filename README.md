# 基金持仓净变动测算（拆股 / 换股折算）

Flask + SQLite 网页应用：上传同一基金前后两期完整持仓 CSV 与换股公告 CSV，
按公告逐日折算期初持仓，按期末代码输出折算来源、折算股数、实报股数与净变动。

## 折算规则

- 公告区间为 **(期初日, 期末日]**：期初日次日起生效，期末日当天含在内；
  期末持仓尚未上传时窗口上不封顶（预览），上传后再约束到期末日。
- 同日、同一旧代码最多一条公告（上传时强校验，违规整表拒绝）。
- 每个交易日先**冻结当日起始余额**，所有折算基于起始余额；
  **新换得的份额当天不再折算**，日内转换在收盘阶段统一结算。
  例如同日 `A→B (1:2)`、`B→C (1:5)`：A 换入的 B 当天保留，
  只有 B 的起始余额被折成 C。
- 全程 `Decimal` 运算，**中间不取整、不截断**；份额以规范化字符串入库。
- 净变动 = 实报股数 − 折算股数；折算侧或实报侧缺项一律按零计算。
- 同一期末代码由多个期初来源合并时，逐来源展示折算路径与份额。

## CSV 格式

持仓 CSV（表头支持中英文别名，证券代码按文本保留前导零）：

```
证券代码,股数
000001,100
000002,200
```

公告 CSV（新旧股数比 = 每 1 股旧代码换得的新代码股数）：

```
生效日,旧代码,新代码,新旧股数比
2026-01-15,000001,000001X,3
```

## 公告整表换报与增量重算

- 公告按整表替换：新表先解析校验，失败仅登记 `failed` 批次，
  原 `active` 表与既有结果完全不动、仍可查询。
- 换报时用代码级轻量模拟（只跟踪代码、不算股数）对比新旧公告，
  **只对可能受改动影响的期初持仓做完整股数重算**，
  未受影响来源沿用上一结果批次的折算行，结果批次中注明重算/沿用条数。
- 公告批次（active / superseded / failed）与全部历史结果批次均可在页面查回。
- 持仓同周期重复上传按整表替换，自动触发全量重算；历史持仓文件保留。

## 期末合表（分账户报表 + 合并报表）

托管行会同时交分账户报表和合并报表。上传期初持仓后，在「期末合表」区域
填写报告日与应报账户（最多 12 个），一次上传该日的多份期末持仓 CSV
（沿用原持仓格式），每份从名单里勾选其覆盖的账户：

- **每份文件只能整表采用**，不能跨文件挑证券；
- 每个应报账户在选定组合里**恰好出现一次**；某份文件缺行即按零计入；
- **所有能凑齐的组合都须得出相同的逐证券股数**，否则核对失败。

核对结论：

| 情形 | 处理 |
| --- | --- |
| 凑不齐 | 提示原因（哪个账户无人覆盖、哪些账户的候选文件必然重叠），不生效 |
| 能凑齐但股数不同 | 列出两组组合的采用文件 + 至少一项逐证券差异，不生效 |
| 能凑齐且所有可行组合一致 | 核对通过，合并期末持仓与净变动表**同一事务一起生效** |

一致性核对**不枚举全部组合**：把文件对账户的覆盖视为 0/1 矩阵，
先在账户覆盖的列空间上一次性判定多数证券恒定；列空间外的证券用
账户子集 DP（状态数 `2^账户数`，最多 4096）求最小/最大合计，
极值相等即证明这只证券在所有可行组合下恒定。整个过程不列出、不存储组合。

其他约束：

- 核对计算不占用数据库写锁，**核对期间仍可用原入口上传期末持仓**；
- 若核对开始后（或草稿入库后）有新的期末表先入库，本次合表标记
  `retry_required`，提示重试且不覆盖新表；页面上可勾选「以当前期末表为
  基线重新核对」显式重试；
- 核对失败/重试时，任何已生效的期末持仓与结果都不改动，旧结果仍可查；
- 核对通过后页面显示本次采用的文件（合表批次页「已采用」标记，
  结果页与持仓列表显示「合表采用：…」），合并后的期末持仓进入历史持仓，
  后续公告换报会按最新结果批次常规重算。

## 本地运行

```bash
pip install -r requirements.txt
python run.py            # http://127.0.0.1:8000
```

## Docker Compose 启动

```bash
docker compose up --build -d
# 打开 http://localhost:8000
```

SQLite 数据库与上传的原始 CSV 持久化在命名卷 `fund-data`（容器内 `/data`）。
单 gunicorn worker + 多线程，配合 SQLite WAL。

## 测试

```bash
python -m pytest tests/ -q
```

覆盖：折算引擎（拆股、日期边界、同日链、合并、不取整）、
服务层（净变动缺项按零、换报增量、换报失败可查、重复代码拒绝）、
期末合表（凑不齐/多解一致/多解不一致、12 账户规模、核对期间新表重试、
失败不动已生效数据）、网页端到端（上传、换报、合表勾选与生效、flash 提示）。

```
app/csv_utils.py     CSV 解析与校验
app/db.py            SQLite schema 与连接管理
app/services.py      上传/换报/增量重算/期末合表/净变动查询
app/routes.py        网页路由
app/templates/       单页界面
tests/               pytest 测试
```
